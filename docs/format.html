Model and decoder formats

The model uses Georgi Gerganov's Unified Format (GGUF), a binary model container. It stores the source model configuration and four tensor namespaces: denoiser, octree, Gaussian and background remover.

The native decoder consumes a local manifest and weights file derived from the model. The conversion preserves supported eight-bit and four-bit blocks; its cache records hashes for the model and generated files. The two separately licensed image encoders are not embedded in this container.
