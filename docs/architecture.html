Architecture

The Python entry point loads Idol's denoiser and background remover from the model container and uses the upstream image encoders and sampler. The command-line path can use native C++ octree and Gaussian decoders; the reusable graphics-device server uses the upstream decoder architecture with packed weights.

The released mixed-precision model stores eligible matrices from all four Idol components in eight-bit blocks. Depending on runtime options, quantized matrices are expanded when loaded or kept packed for graphics-device inference.
